# Visual Reference Guide

_Reference language and usage guide for Gloamstead's art direction._

## Purpose

This document explains how to use visual references without reducing Gloamstead to “Game A plus Game B.” References are directional tools, not identity statements.

The internal art-direction label is:

> **Withered Gothic Realism**

Expanded description:

> A painterly, romantic dark-fantasy realism with liminal memory atmospherics and ritualized restoration.

## Reference Buckets

### 1. Withered Romantic Realism

Use for emotional tone, composition, and melancholy beauty.

Reference qualities:

- late-romantic landscape mood
- sacred loneliness
- small light against vast darkness
- silhouettes in mist
- ruins as emotional landscape
- fragile warmth in cold environments

Production translation:

- strong horizon compositions
- low, lonely light sources
- restrained warm accents
- atmospheric depth
- quiet ruin staging

### 2. Painterly Gothic Realism

Use for the main rendering philosophy.

Reference qualities:

- believable materials
- gothic forms
- painterly texture restraint
- stylized silhouettes
- cinematic fog and rim light
- grounded but emotionally directed lighting

Production translation:

- PBR base with controlled roughness and color grading
- reduced texture noise in secondary surfaces
- stronger shape readability on important objects
- architectural decay that feels authored, not random

### 3. Liminal Memory Realism

Use for atmosphere, corruption, perception, and special night states.

Reference qualities:

- half-remembered spaces
- soft or unstable edges
- dreamlike distance treatment
- afterimages
- fog with emotional behavior
- reality becoming clearer through restoration

Production translation:

- corrupted spaces can have subtle edge instability
- distant ruins may dissolve into fog or memory haze
- restored objects can leave faint after-glow
- dawn can sharpen edges and reduce perceptual noise

### 4. Ritualistic Naturalism

Use for restorable structures and sanctuary layout.

Reference qualities:

- roots and stone integrated as intentional systems
- ceremonial object placement
- natural forms shaped by ritual use
- ancient repairs, markings, offerings, thresholds
- structures that imply meaning before mechanics

Production translation:

- lanterns placed like path-memory anchors
- gardens arranged as stabilizing life circles, not decoration beds
- mirrors built into shrines, arches, pools, or truth-sites
- bells framed as invitation/warning instruments
- roots and boundaries forming living threshold logic

### 5. Luminous Ruin Fantasy

Use only for precious restoration accents.

Reference qualities:

- sacred glow
- teal-gold life accents
- motes and quiet bloom
- bioluminescent hints
- miraculous reveals in ruined places

Production translation:

- Veil Heart glow
- lantern warmth
- dawn payoff
- restored garden bloom
- sanctuary healing pulses

Do not use this as the baseline. It is the reward layer.

### 6. Ashen Mythic Discipline

Use as a palette and tone constraint.

Reference qualities:

- cold ruin palettes
- sparse sacred compositions
- ash, stone, dead wood, old iron
- ancient world feeling
- warmth as rarity

Production translation:

- unrecovered areas remain desaturated
- restored warmth is localized
- broad saturation is avoided
- beauty comes from contrast, not constant color richness

### 7. Bleak Mineral Accent

Use for specific corruption, fracture, or petrification moments.

Reference qualities:

- fossilized life
- obsidian veins
- crystalline corruption
- faceted unnatural surfaces
- arrested organic growth

Production translation:

- corrupted roots may look mineralized
- fracture nights may use hard facets or broken refraction
- late-stage corruption can make living things look petrified

Do not make this the full world identity.

## Reference Use Rules

### Good Reference Use

A reference is useful when it answers one of these:

- How should restoration feel?
- How should the sanctuary contrast with the world?
- How should fog behave?
- How should a night consequence read visually?
- How should a symbolic structure communicate its function?
- How should the Veil Heart feel wounded, alive, and miraculous?

### Bad Reference Use

A reference is risky when it only answers:

- How do we make this look expensive?
- How do we make this look like a Soulslike?
- How do we make this more photoreal?
- How do we add more detail everywhere?
- How do we make the environment prettier without supporting gameplay?

## Asset Reference Questions

For every major art reference, ask:

1. Does this strengthen bleak-but-recoverable tone?
2. Does this help the player read meaning or consequence?
3. Could this become too generic if used literally?
4. Is the warmth earned or default?
5. Does it support restoration, warning, and night consequence?
6. Is it visually readable in fog, dusk, and night?

## Internal One-Line Reference Statement

Use this when describing the visual target quickly:

> Gloamstead is grounded dark fantasy shaped like a melancholy painting, where a dying world regains warmth, clarity, and sacred light through ritual restoration.
