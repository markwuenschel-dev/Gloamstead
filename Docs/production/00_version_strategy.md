# Version Strategy

_How to prototype and build the current version without scope creep._

## First Prototype Goal

Prove the smallest complete loop:

> warning -> interpretation -> restoration -> night consequence -> dawn feedback

## Prototype 1: The First Night

Required:

- third-person controller
- one small ruined sanctuary area
- Veil Heart object
- one warning fragment
- one restorable lantern or equivalent structure
- one simple night threat
- one cleansing/combat input
- dawn feedback

Do not include:

- inventory
- crafting resources
- village management
- multiple weapons
- open world
- tower defense structures
- many build pieces
- procedural systems

## Prototype 2: Three Rule Nights

Add two more night consequence types.

Possible sequence:

1. Light/path tutorial night.
2. Corruption night.
3. Possession or retrieval night.

Goal: test whether players understand that nights are rule tests, not waves.

## Prototype 3: Restoration Choice

Allow the player to choose between two or three restorations before night. Each choice changes the night.

Goal: test agency, interpretation, and consequence.

## Vertical Slice

A polished 30-60 minute slice should include:

- 3-5 restored structures
- 3-4 night types
- meaningful Heart clarity progression
- one small explorable ruined area
- one strong dawn payoff
- one failure case
- simple combat and cleansing only

## Commercial Scope Direction

The game may become a focused 2-6 hour experience first. That length supports high polish, mystery, and strong atmosphere without forcing survival-game sprawl.
